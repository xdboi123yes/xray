## 1. `architecture.png` — System overview  (label `fig:architecture`, Chapter 3)

A left-to-right pipeline:

1. **Input** — "Chest radiograph (PNG/DICOM)".
2. **Preprocessing** — one box: "CLAHE → resize 224×224 → ImageNet normalization".
3. **Tier 1 — MobileNetV2** — outputs a probability `p₁` and a confidence score.
4. **Routing decision** (diamond) — "confidence ≥ τ ?" where τ = 0.75 (dynamic).
   - **Yes → Accept Tier-1 decision** (arrow straight to Output). Annotate this
     path "≈ 74 % of cases" (escalation rate is ≈ 26 %, from A13 `percent_tier2`).
   - **No → Escalate** (arrow down to Tier 2). Annotate "≈ 26 % of cases".
5. **Tier 2 — EfficientNet-B4 / Ark+ Swin** — drawn as the heavier model. Inside
   or beside it, show the two uncertainty modules:
   - "MC-Dropout (T = 20 stochastic passes)"
   - "Test-Time Augmentation (10 views)"
   → outputs mean probability + variance σ².
6. **Conformal Prediction** — box: "Calibrated quantile q̂, target coverage
   1 − α = 0.95" → emits a prediction *set* (one or both labels).
7. **Output** — "Prediction + confidence + uncertainty (σ²) + conformal set +
   flag-for-review". 

Keep Tier 1 visually light/small and Tier 2 heavy/large to convey the
compute-saving idea.

## 2. `routing_flowchart.png` — Confidence-based routing  (label `fig:routing`)

A top-to-bottom flowchart of the *decision logic* (complements the architecture):

1. **Start** — "Tier-1 inference → confidence c".
2. **Dynamic threshold** — box: "Sliding window of last 50 confidences →
   adapt τ around 0.75 by δ = 0.05".
3. **Decision** (diamond) — "c ≥ τ ?"
   - **Yes →** "Accept Tier-1 prediction" → **End**.
   - **No →** continue down.
4. **Tier-2 inference** — "MC-Dropout (T = 20) + TTA (10) → mean prob, variance σ²".
5. **Decision** (diamond) — "σ² > 0.08 ?" → **Yes:** set "flag for radiologist
   review". (0.08 is the variance flag threshold used in the live app.)
6. **Conformal set** — "set size > 1 ? → abstain (return both labels)".
7. **End** — "Final decision + confidence + uncertainty + conformal set".
